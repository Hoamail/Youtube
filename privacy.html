Privacy Policy

Application: CreatorFlow Studio Effective Date: November 14, 2026 Scope: Internal Creator Tool

1. Introduction & Purpose

This Privacy Policy outlines how CreatorFlow Studio ("we", "our", or "the Application") interacts with user data and Google APIs. CreatorFlow Studio is an internal productivity tool created solely to assist authenticated content creators in automating video rendering and scheduling video uploads directly to their own YouTube channels via the YouTube Data API v3.

We take personal privacy and data security seriously. CreatorFlow Studio does not operate as a public commercial service, does not host external user accounts, and is designed with a strict principle of minimal data access and zero third-party data collection.

Authorized Channel Only

Actions are performed exclusively on the specific YouTube channel owned and authorized by you.

No Data Selling / Sharing

We do not collect, monetize, sell, lease, or share personal data with any third party.

Local Token Storage

OAuth tokens are kept strictly in local secure storage, never routed to external servers.

2. Google API Access & How We Use Data

CreatorFlow Studio uses Google OAuth 2.0 to request explicit permission to interact with your YouTube account. Specifically, our application requests access to the following Google API scope:

  • https://www.googleapis.com/auth/youtube.upload: Used exclusively to upload your locally rendered video files, assign metadata (title, description, tags, category, custom thumbnail), and set the scheduled publication time on your channel.

Specific and Limited Purpose: Data received via the YouTube Data API is processed strictly to execute actions requested directly by you within the app's workflow. The application only uploads videos that you have selected, rendered, and approved for upload to your own channel.

3. Information We Do Not Collect, Store, or Share

To maintain absolute privacy, CreatorFlow Studio implements the following strict data practices:

  • No Third-Party Data Collection: We do not collect, read, or track data belonging to any third-party viewers, subscribers, commenters, or other YouTube users.
  • No Remote Data Harvesting: We do not operate remote databases or analytical trackers that capture your identity, browsing habits, or device telemetry.
  • No Data Transfer or Resale: We never sell, transfer, disclose, or distribute Google user data or personal identifiers to any third-party advertisers, data brokers, or external entities.
  • No AI Model Training on Private Data: We do not use your private channel data or video content to train generalized artificial intelligence or machine learning models.

4. Token Storage & Security Measures

Upon granting authorization via Google OAuth 2.0, an access token and a refresh token are generated:

  • OAuth tokens are stored locally on your machine in encrypted or restricted-access configuration storage.
  • Tokens are utilized strictly by your local instance of CreatorFlow Studio to authenticate direct, encrypted HTTPS requests to official Google API endpoints.
  • Tokens are never transmitted to any third-party servers, intermediate proxies, or external destinations.

5. Google API Services User Data Policy Compliance

Limited Use Disclosure

CreatorFlow Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking Access & Data Deletion

You remain in full control of your YouTube and Google account at all times. You can immediately revoke CreatorFlow Studio's access through Google's account security dashboard:

  • Visit your Google Account Permissions page: https://myaccount.google.com/permissions
  • Locate CreatorFlow Studio in the list of third-party apps with account access.
  • Click "Remove Access".

To delete all local authentication credentials from your environment, simply delete the local credentials/token file within your CreatorFlow Studio installation folder. Because we do not maintain remote databases containing your data, this action completely purges all association with the application.

7. Changes to This Policy

If any changes are made to the scope of YouTube Data API integration or application features, this document will be updated accordingly with a revised "Effective Date".
